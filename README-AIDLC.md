# ai-driven

AI 駆動開発を、場当たり的なチャットではなく、再利用できる開発テンプレートと最小限の記録で進めるためのリポジトリです。

開発サイクルの基準となる情報に加え、将来も必要になる判断、現在未解決の事項、進行中の作業と進捗だけを管理します。実装内容や変更履歴を重複して記録しません。

## 目的

- アイデア段階の曖昧な要望を、実装可能な単位まで整理する
- AI エージェントに渡す前提、作業範囲、完了条件を明確にする
- 複数セッションでも現在の作業状態を引き継げるようにする
- 将来の作業でも必要な判断だけを残す
- 未解決事項を後続の作業へ引き継げる状態にする

## ディレクトリ構成

```text
.
├── AGENTS.md
├── CLAUDE.md
├── README.md
└── docs/
    ├── 00_base/
    │   ├── 00_idea.md
    │   └── 01_implementation.md
    ├── 01_decision/
    │   └── 00_template.md
    ├── 02_open/
    │   └── 00_template.md
    └── 03_task/
        └── 00_template.md
```

### `AGENTS.md`

AI エージェントが作業するときの入口です。必要なドキュメントの読み方、記録する条件、各ディレクトリの責務を定義します。

### `docs/00_base/`

現在進行中の1開発サイクルの基準となる情報を扱います。日々変わる進捗やタスクは置きません。

- `00_idea.md`: 何を、なぜ作るか。MVPや成功条件を整理する
- `01_implementation.md`: どう作るか。技術、設計、実装スコープ、テストや品質確認の方針を整理する

すべてのタスク完了後に `00_idea.md` のMVPと成功条件を満たしていることを確認します。開発サイクル完了時に、将来必要な判断を `docs/01_decision/`、未解決事項を `docs/02_open/` へ残し、次の作業開始時に2ファイルを再利用します。過去の内容は Git 履歴を参照します。

### `docs/01_decision/`

後続の作業や別セッションでも必要になる、長期的に有効な判断と理由を記録します。

コードや `docs/00_base/` を見れば分かる内容は重複して記録しません。記録の作成や整理は `00_template.md` のルールに従います。

### `docs/02_open/`

現在は解決できず、対応内容や方針がまだ決まっていない事項を記録します。

解決した事項は削除し、重要な判断になった内容だけを必要に応じて `docs/01_decision/` に残します。過去の内容は Git 履歴を参照します。記録の作成や整理は `00_template.md` のルールに従います。

### `docs/03_task/`

現在進行中または後続へ持ち越す作業と、その現在の進捗を記録します。

AIエージェントは、可逆的なリポジトリ内編集、既存の検証、task更新を自律的に進められます。taskの選択順、検証と受入確認のループ、停止条件は [`docs/03_task/00_template.md`](docs/03_task/00_template.md) を参照してください。

1タスク1ファイルにはせず、関連する作業をテーマ単位でまとめます。完了したタスクは削除し、過去の内容は Git 履歴を参照します。

## 基本ワークフロー

```text
idea
  ↓
implementation policy
  ↓
task
  ↓
implementation
  ↓
MVP / success criteria check
```

作業中に対応方針が未確定の事項が見つかった場合は `docs/02_open/`、後続でも必要になる判断をした場合は `docs/01_decision/` に記録します。

## 記録の使い分け

| 状態 | 記録先 | 例 |
| --- | --- | --- |
| 長期的に必要な判断 | `docs/01_decision/` | 技術選定の理由、将来も守る制約、採用しなかった案の理由 |
| 対応内容や方針が未確定 | `docs/02_open/` | ユーザ確認待ち、判断待ち、調査が必要な不明点 |
| 実施内容が決まっている未完了作業 | `docs/03_task/` | 実装、調査、検証、移行、後で対応する修正 |
| その場で完結する内容 | 記録しない | 軽微な修正、完了した調査、通常のレビュー結果 |

詳細な運用ルールは `AGENTS.md` を参照してください。
