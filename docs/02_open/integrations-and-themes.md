# 連携とテーマの未解決事項

## Git / Notion 連携の必要性

### Context

Git / Notion 連携は候補に挙がっているが、現時点では必要性、対象操作、利用者の期待する同期範囲が未確定である。ローカル Markdown を唯一の保存形式とする現在の方針、認証情報、ネットワーク利用、競合時のデータ保護へ影響するため、実装タスクにはしない。

### Next

- Git: status / diff / commit / branch のどこまでを扱うか、認証や既存リポジトリへの影響、競合時の挙動を確認する。
- Notion: インポート・エクスポート・一方向同期・双方向同期のどれを望むか、認証、オフライン、Markdown 変換、競合、プライバシーを確認する。
- 必要性と方針が決まった時点で、実装 task と長期 decision を作成する。

## VS Code 系カラーテーマの採用

### Context

コードブロックを含むカラーテーマを再検討する予定だが、VS Code 系テーマをそのまま採用するか、色だけを参考にした独自テーマとするかは未決定である。ライセンス、依存サイズ、Milkdown / ProseMirror への適用方法、可読性とアクセシビリティを確認する必要がある。

### Next

- 候補テーマとライセンスを比較する。
- コードハイライトの導入方式と bundle への影響を調査する。
- 通常本文、リスト、選択状態、コードブロックを含む配色評価を行い、採用方式を決定する。
