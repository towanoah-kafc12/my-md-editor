# エディタ機能拡張の未解決事項

## 設定画面からのフォントサイズ変更

### Context

エディタの文字サイズを、設定画面から利用者が変更できるようにしたい。対象範囲（編集ペインのみか、プレビューやアプリ全体も含めるか）、選択肢または最小・最大値、設定の保存先と反映タイミングが未確定である。

### Next

- フォントサイズを適用する画面・要素を決める。
- 変更方法（段階選択または数値指定）とデフォルト値、許容範囲を決める。
- 設定の永続化方法と、変更後の即時反映・リセットの挙動を決める。

## サイドバーのファイル・フォルダ作成

### Context

開いているフォルダのファイルツリーを表示するサイドバーから、フォルダ作成と Markdown ファイルの新規作成をできるようにしたい。作成できるファイル種別は Markdown のみを想定する。作成場所の選び方、名前の検証、既存項目との重複時の挙動、作成後に開くかどうかが未確定である。

### Next

- 新規フォルダ・新規 Markdown ファイルの操作導線と作成先の決め方を定める。
- ファイル名・フォルダ名の入力規則、拡張子の補完、重複時の挙動を決める。
- 作成後のツリー更新、対象ファイルを開く挙動、失敗時の表示を決める。

## Markdown への画像貼り付けとローカル保存

### Context

Markdown の編集時に画像を貼り付けた場合、Markdown ファイルと同じ階層にそのファイル名のフォルダを作成し（未作成の場合）、貼り付けた画像を適当なファイル名で保存して Markdown から参照・表示したい。VS Code 拡張の [Paste Image](https://marketplace.visualstudio.com/items?itemName=mushan.vscode-paste-image) を利用イメージとする。対象の貼り付け元、画像形式・命名規則、既存ファイルとの衝突、未保存 Markdown や読み取り専用場所での扱い、相対パスの形式が未確定である。

### Next

- 対象とする貼り付け元（クリップボードの画像、ファイル貼り付けなど）と対応画像形式を決める。
- 画像保存先のフォルダ名・命名規則・衝突回避方法を決める。
- Markdown に挿入する相対参照形式と、エディタ・プレビューでの表示要件を決める。
- 未保存ファイル、書き込み失敗、読み取り専用フォルダなどの例外時の挙動を決める。
