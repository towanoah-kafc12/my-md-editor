# Implementation Policy Template

使う技術、設計方針、実装方針、スコープ、テストや品質確認の方針を保存するためのテンプレートです。  
アイデア詳細化後、タスク作成や実装に入る前にこのファイルを埋め、AIエージェントが実装時に参照できる状態にします。

## 基本情報

| 項目            | 内容                      |
| --------------- | ------------------------- |
| 項番            | 1                         |
| 日付            | YYYY-MM-DD                |
| 対象機能 / 作業 |                           |
| 関連する idea   | `docs/00_base/00_idea.md` |
| 関連する open   | `docs/02_open/`           |
| 状態            | 草案 / 確定 / 要更新      |
